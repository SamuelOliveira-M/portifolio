Projetos

SEMG.EDU

O sistema SEMG.Edu foi desenvolvido do completo zero com o objetivo de facilitar o lançamento de notas e a gestão escolar. Inclui telas de cadastro e login para que os professores e administradores possam acessar o sistema de forma segura. Além disso, possui interfaces exclusivas para os administradores, que permitem adicionar turmas, alunos, lançar notas e visualizar relatórios de desempenho. Foi desenvolvido em React e no back-end Express.js, PostgreSQL (Sequelize). Implementação de autenticação JWT, segurança com bcrypt e validações com Yup. Utilização de ESLint, Prettier e Nodemon para garantir um código limpo e eficiente.

Corenotes

Corenotes é uma aplicação web de bloco de notas interativo que permite a edição simultânea de documentos por múltiplos usuários em tempo real. O sistema foi desenvolvido com foco em colaboração, sincronização instantânea e alta performance na recuperação de informações. A aplicação possibilita que vários usuários criem, editem e visualizem notas compartilhadas de forma sincronizada, garantindo atualização automática do conteúdo entre todos os participantes conectados. Para otimizar a experiência de busca e organização dos conteúdos, o CollabPad integra o Elasticsearch, permitindo pesquisas rápidas e eficientes entre grandes volumes de blocos de notas. A indexação dos documentos possibilita consultas quase instantâneas, filtragem dinâmica e localização ágil de informações relevantes
