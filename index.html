Projetos

Sistema SEMG.Edu: Transformando a Gestão Escolar. O sistema SEMG.Edu foi desenvolvido do completo zero com o objetivo de facilitar o lançamento de notas e a gestão escolar. Inclui telas de cadastro e login para que os professores e administradores possam acessar o sistema de forma segura. Além disso, possui interfaces exclusivas para os administradores, que permitem adicionar turmas, alunos, lançar notas e visualizar relatórios de desempenho. Foi desenvolvido em React e no back-end Express.js, PostgreSQL (Sequelize). Implementação de autenticação JWT, segurança com bcrypt e validações com Yup. Utilização de ESLint, Prettier e Nodemon para garantir um código limpo e eficiente.
